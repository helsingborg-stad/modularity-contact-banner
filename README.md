# modularity-contact-banner
Contact Banner module for modularity

## Getting Started
Get the latest version and follow the installation steps bellow.

### Dependencies
WordPress, Municipio and Modularity (version 2.11.0 or higher). WPService 3
requires PHP 8.2 through 8.5.

When resolving dependencies in one Composer project, Modularity 6.90.41's
WPService ^2.0 constraint conflicts with WPService 3. A compatible Modularity
release is required.
